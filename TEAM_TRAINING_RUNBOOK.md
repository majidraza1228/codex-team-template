# Team Training Runbook

Use this to run a short workshop for teaching the Codex operating model.

## Goal

Teach the team to stop using Codex as a blank-slate chat tool and start using it as a structured system.

## 60-minute agenda

### 1. Framing: 10 minutes

- explain prompt vs `AGENTS.md` vs skill vs hook vs agent vs memory
- introduce the layering model

### 2. Before and after examples: 10 minutes

- show a weak task request
- rewrite it using objective, scope, constraints, context, and verification

### 3. Repo instructions: 10 minutes

- walk through a strong `AGENTS.md`
- show what should not be included

### 4. Skills and hooks: 10 minutes

- show one good skill
- show one good hook
- explain when each is appropriate

### 5. Evals and memory: 10 minutes

- explain why one successful run is not enough
- explain what should and should not become memory

### 6. Exercise: 10 minutes

- have the team convert one real recurring workflow into a skill

## Suggested exercises

### Exercise 1

Rewrite a vague request into a strong Codex task.

### Exercise 2

Take a repeated workflow and turn it into a skill.

### Exercise 3

Identify which repo rules belong in `AGENTS.md` versus hooks.

## What good outcomes look like

- the team uses shorter but clearer requests
- repo instructions become explicit
- repeated work stops being re-explained
- guardrails are visible and intentional

## Follow-up

After the workshop, pick one pilot repo and implement:

- one real `AGENTS.md`
- three real skills
- two lightweight hooks
- one small eval set
