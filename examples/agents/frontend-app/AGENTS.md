# Project Instructions

## Mission

- This repo provides a frontend application.
- UX consistency and visual verification matter as much as code correctness.

## Read First

- `README.md`
- `src/`
- `components/`
- `pages/`
- `design-system/`

## Commands

- Run app: `npm run dev`
- Tests: `npm test`
- Lint: `npm run lint`
- Build: `npm run build`

## Working Rules

- Preserve the existing design language unless a redesign is requested.
- Avoid broad refactors during feature or bug-fix tasks.
- Reuse existing components before creating new ones.

## Verification

- UI changes require visual verification.
- Behavior changes require targeted tests when the repo supports them.

## Team Skills To Prefer

- `bug-fix`
- `review-comment-resolution`
- `prompt-change-with-eval`
