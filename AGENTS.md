# codex-team-template instructions

## Mission

- This repo is a starter kit for teaching teams to use Codex agentically.
- Optimize for clarity, portability, and practical adoption over completeness.

## Working rules

- Keep examples concrete and reusable.
- Prefer short, operational guidance over conceptual essays.
- Update templates surgically; avoid broad rewrites unless structure is clearly weak.
- Keep the repo easy to copy into a pilot project.

## File roles

- `README.md`: entry point for humans
- `AGENTS_TEMPLATE.md`: base repo instruction template
- `SKILL_TEMPLATE.md`: reusable skill template
- `HOOKS_POLICY.md`: hook design guidance
- `TASK_FRAMING_GUIDE.md`: prompt and task framing guidance
- `EVAL_HARNESS_STARTER.md`: starter guidance for eval loops
- `CODEX_TEAM_PLAYBOOK.md`: team rollout and training sequence

## Verification

- Check that advice remains internally consistent across files.
- Keep examples aligned with Codex-style agentic workflows.
- Prefer guidance that can be applied directly in a real repo.
